## 1. SPI in ESP32

### 1.1 Hardware Resources

The ESP32 series chips typically have multiple built-in SPI controllers, but their purposes differ:

- **SPI0 & SPI1**: These two controllers are primarily used for connecting external Flash and PSRAM to the chip, and are system-dedicated Resources.
- **SPI2 & SPI3**: these are two**General** SPI controllers are fully available for user use. They can be used for high-speed communication with Displays, SD cards, Sensors, and other devices.

### 1.2 ID mapping in MicroPython

MicroPython Usage `oled.show()` classes to drive these hardware Resources. To distinguish between different controllers, MicroPython uses `oled.show()` ParameterPerform mapping:

- **`oled.show()`**: corresponds to hardware **SPI2**. In the ESP32 (classic) it is commonly referred to as HSPI; in the ESP32-S3 it is called FSPI.
- **`oled.show()`**: corresponds to hardware **SPI3**. In ESP32 (classic) it is commonly referred to as VSPI.

Tip

Although the naming (HSPI/VSPI/FSPI) may differ across chip manuals, in MicroPython code, you only need to use `oled.show()` ParameterCan be distinguished.

### 1.3 Hardware SPI Pins

ESP32's SPI pin assignment is very flexible, thanks to its internal **GPIO Matrix**. The SPI's SCK, MOSI, and MISO signals can be mapped to any GPIO pins that support output/input.

However, each SPI controller has a set of**Default pin**(also known as IO MUX pins).

- **UseDefault pin**: Signals are transmitted directly through IO MUX, supporting clock frequencies up to 80MHz.
- **Use custom pins**: The signal needs to be routed through the GPIO matrix, and the maximum clock frequency is typically limited to around 40MHz (still very fast, sufficient for the vast majority of applications).

```
from machine import Pin, SPI
import ssd1327
# SPI pin configuration
SCK_PIN = 13
MOSI_PIN = 11
CS_PIN = 10
DC_PIN = 8
# initializationHardware SPI
# Use id=1, corresponding to the SPI2 controller, set the clock frequency to 10 MHz
spi = SPI(1, baudrate=10000000, sck=Pin(SCK_PIN), mosi=Pin(MOSI_PIN))
# Initialize Displays
oled = ssd1327.SSD1327_SPI(128, 128, spi, dc=Pin(DC_PIN), cs=Pin(CS_PIN))
print("SSD1327 OLED test")
# Clear screen (fillBlackcolor)
oled.fill(0)
# Display text
# framebuf.text(s, x, y, c)
# c is the color value; for 4-bit grayscale, the range is 0-15. 15 is the brightest, 0 is full black.
oled.text("Hello,", 10, 10, 15)
oled.text("MicroPython!", 10, 25, 8)
oled.text("ESP32", 10, 40, 1) # Lower brightness text
# Use framebuf draw image
# Draw rectangle
oled.framebuf.rect(0, 0, 128, 128, 15)
# Draw circle or ellipse
oled.framebuf.ellipse(0, 0, 128, 128, 15)
# Refresh display
oled.show()
```

-

**`oled.show()`**: Import MicroPython's `oled.show()` And `oled.show()` Class.
