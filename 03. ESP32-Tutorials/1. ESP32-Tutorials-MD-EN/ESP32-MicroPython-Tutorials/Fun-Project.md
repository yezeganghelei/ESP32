# number (ordinal prefix) 12 section comprehensiveProject

This section showcases comprehensive projects built with MicroPython, through which you can apply the knowledge learned in previous chapters to practical projects.

- [**Traffic Light**](../ESP32-MicroPython-Tutorials/12-1-Traffic-Light.md): Control multiple LEDs to simulate traffic light timing logic.
- [**SOS**](../ESP32-MicroPython-Tutorials/12-2-SOS.md): Control the buzzer and LED to emit SOS Morse code signals.
- [**Presence-Sensing Light**](../ESP32-MicroPython-Tutorials/12-3-Presence-Light.md): Use PIR Sensors to detect human motion and control the WS2812 light strip on/off.
- [**Fun LED Strip**](../ESP32-MicroPython-Tutorials/12-4-LED-Strip.md): Use a potentiometer to real-time control the color changing effect of a WS2812 LED strip.
- [**Interactive Progress Bar**](../ESP32-MicroPython-Tutorials/12-5-Progress-Bar.md): Use a potentiometer to real-time control the progress bar and gauge displayed on the OLED screen.
- [**Weather Display**](../ESP32-MicroPython-Tutorials/12-6-Weather-Display.md): Connect to the Xinzhi Weather API in real time via Wi-Fi to obtain weather data and display it on the OLED screen.
