# ESP-IDF Introductory Tutorials

Welcome to Waveshare ESP-IDF Introductory Tutorial!

This Tutorials aims to help developers quickly get familiar with the basic concepts of ESP-IDF and start development. Content covers environment setup, project creation, component usage, and peripheral programming. Helping you take your first step in ESP-IDF programming.

Important Note: About Hardware and Software Versions

**Hardware**: The core logic of this tutorial applies to all ESP32 development boards, but all operation steps are based on （) as examples. If you use other Models of Development Boards, please modify the corresponding settings according to your actual situation. It is recommended to use development boards based on **ESP32-S3**  Development Boards for a consistent learning experience.
**Software**: This Tutorials is based on **ESP-IDF v6.0**  version. ESP-IDF is continuously updated, and there may be API or project configuration compatibility issues between different major versions. ESP-IDF uses[Semantic Versioning](https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32s3/versions.html#versioning-scheme), minor versions are usually compatible. To ensure code reproducibility, it is recommended to use the same version as this Tutorials or **ESP-IDF v6.x**  version.
