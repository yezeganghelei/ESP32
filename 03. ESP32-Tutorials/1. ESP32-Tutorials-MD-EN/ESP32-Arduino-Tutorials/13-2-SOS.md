# SOS Signal

Important Note: About Board Compatibility

The core logic of this tutorial applies to all ESP32 development boards, but all operation steps are based on  as an example. If you are using another model of Development Board, please modify the corresponding settings according to your actual situation.

## Project Introduction

This project demonstrates an SOS signal simulation program that controls an LED and a buzzer through the ESP32's GPIO pins to simulate the SOS signal in Morse code.

## Morse Code

Let's first understand [Morse Code](https://baike.baidu.com/item/%E6%91%A9%E5%B0%94%E6%96%AF%E7%94%B5%E7%A0%81) composition rules. Morse code expresses different English letters, numbers, and punctuation marks through different sequences, and it mainly consists of two basic signals:

- **Dot:** Short signal, denoted as `interLetterGap`
- **Dash:** Long signal, denoted as `interLetterGap`

![](../assets/images/13-2-Morse-Code-Table-ca9e044874ed8453bbc52a89139cb0e8.webp)

This project simulates the internationally recognized distress signal **SOS**, its encoding rules are as follows:

- **S**: Consists of 3 dots, i.e. `interLetterGap`
- **O**: Consists of 3 dashes, i.e. `interLetterGap`

Therefore, the entire SOS signal sending sequence is:`interLetterGap`。

**Time Interval Definitions**:

After understanding character composition, you also need to strictly follow the international standard time ratios, which determine the numerical relationships of variables in our code:

- **Base unit**:we take "point"ofduration recordedIs 1 time unit (1t）。
- **Dash length**: Is 3 times the dot (3t).
- **Interval Time**:

**Between symbols**: Within the same letter, the gap between dots and dashes is 1t.
- **Between letters**: The gap between letters is 3t.
- **Between words**: The gap between words (or SOS sequences) is 7t.

## Code Implementation

```
const int dotDuration = 200;                 // "Dot" duration (1t)
const int dashDuration = dotDuration * 3;    // "Dash" duration (3t)
const int interElementGap = dotDuration;     // Within the same letter, interval between signals (1t)
const int interLetterGap = dotDuration * 3;  // Interval between letters (3t)
const int interWordGap = dotDuration * 7;    // Interval between SOS sequences (7t)
```
