# ESP32 Arduino Introductory Tutorials

This series of Tutorials is based on Waveshare and Arduino IDE environment, aimed at helping learners get started with ESP32 development. It is recommended to study in order, or you can choose chapters of interest based on your needs.

Important Note: About Board Compatibility

The core logic of this tutorial applies to all ESP32 development boards, but all hardware operation example codes are based on  . To ensure a consistent learning experience, it is recommended to use a Development Board based on **ESP32-S3** chip.
If you use other ESP32 development boards, please note:

- **Different pin definitions**: The pin numbers and functional layout will vary across different Development Boards.
- **Different onboard resources**: For example, your Development Board may use LEDs on different pins, or may not have an onboard RGB LED.

**Before running any examples that interact with hardware, please check your board's pinout diagram and modify the pin numbers in the code to ensure proper operation.**

You can use any ESP32 development board you have, along with your own components to follow along.
