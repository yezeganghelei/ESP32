# Section 13 Comprehensive Projects

This section showcases some comprehensive projects built with Arduino programming. Through these projects, you can apply the knowledge learned in previous chapters to practical projects.

- [**Traffic Light**](../ESP32-Arduino-Tutorials/13-1-Traffic-Light.md): Control multiple LEDs to simulate traffic light timing logic.
- [**SOS**](../ESP32-Arduino-Tutorials/13-2-SOS.md): Control a buzzer and LED to emit SOS Morse code signals.
- [**Presence-Sensing Light**](../ESP32-Arduino-Tutorials/13-3-Presence-Light.md): Use PIR Sensors to detect human motion and control the WS2812 LED strip switch.
- [**Fun LED Strip**](../ESP32-Arduino-Tutorials/13-4-LED-Strip.md): Use a potentiometer to control the color changing effect of the WS2812 LED strip in real-time.
- [**Interactive Progress Bar**](../ESP32-Arduino-Tutorials/13-5-Progress-Bar.md): Use a potentiometer to control the progress bar and dashboard display on an OLED screen in real-time.
- [**Weather Display**](../ESP32-Arduino-Tutorials/13-6-Weather-Display.md): Connect to the Xinzhi Weather API via Wi-Fi in real-time to obtain weather data and display it on an OLED screen.
