If the installation prompt says "Pre-installation successful but the USB serial port is not working properly,"

then manually copy the serenum.sys and serial.sys files to the C:\Windows\System32\drivers folder.

If these files already exist in that folder and the prompt says they cannot be replaced, delete the existing files and copy them over.

Then try again.

This usually resolves the serial port installation/usage issue.

Win7 (shared with XP) -32: Suitable for 32-bit Win7/XP systems.

Win7-64: Suitable for 64-bit Win7 systems.
