This example program is used to test hardware before shipment.

It tests the 6050, camera, microphone, speaker, ADC, buttons, screen, and touchscreen.

esptool.py --chip esp32s3 merge_bin -o 16_test_firmware.bin --target-offset 0x0 --flash_mode dio --flash_freq 80m 0x0 build\bootloader\bootloader.bin 0x8000 build\partition_table\partition-table.bin 0x10000 build\hello-world.bin 0x208000 build\storage.bin 0x366000 build\model.bin
